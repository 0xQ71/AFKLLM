# AFKLLM 0.5.2-20261124

Strata 0.2.20 и DeepSeek Harness 0.2.3: AFKLLM работает с новыми версиями и возвращает скорость, которую новый движок
Strata на картах с 16 ГБ по умолчанию отдаёт.

## Что нового

- **Strata 0.2.20 (движок 0.1.66)**:
  - `afk api` запускает сервер из активной версии Strata (`components\control\<версия>` после `strata update`), а не
    из старой папки установщика — раньше после обновления запускался бы старый сервер;
  - свои настройки движка профиль передаёт через `user_args`: только их сервер Strata не пересобирает при запуске;
  - на 16 ГБ видеокарте движок 0.1.66 оставляет 1280 МБ видеопамяти в резерве и читает промпт кусками по 8192 токена —
    чтение длинного промпта стало на 36–46 % медленнее. Профиль `flash` возвращает 16384-токенные куски
    (`STRATA_NV_CHUNK=16`) и резерв 350 МБ (`--vram-reserve-mib`): экспертов в видеопамяти снова столько же, сколько
    на 0.1.64, свободно ~750 МБ.
- **Замеры** (через `afk api`, одинаковые промпты, без кэша):

  | | 0.2.18 | 0.2.20 как есть | 0.2.20 в AFKLLM |
  |---|---|---|---|
  | генерация, короткий запрос | 60–66 т/с | 58–65 т/с | 62–64 т/с |
  | чтение промпта 30K | 1591 т/с | 1020 т/с | 1658 т/с |
  | чтение промпта 125K | 1939 т/с | 1043 т/с | 1984 т/с |
  | генерация на 125K | 51,8 т/с | 45,9 т/с | 50,9 т/с |
  | факт, спрятанный в 125K | найден | найден | найден |

- **`scripts\strata-setup.cmd`**: контекст 256K и полный подбор настроек (`--tune thorough --retune`); после
  `strata update` его нужно запустить снова.
- **DeepSeek Harness 0.2.3-alpha.2**: профили, хуки, поиск и перевод проверены (прогон headless: задача с тестами,
  запрет хуков на чтение их настроек).
- Тесты: выбор папки Strata и передача флагов (`scripts/strata.test.ts`).

## Обновление

```powershell
git pull; npm install
& "$env:LOCALAPPDATA\Strata\terminal\current\bin\strata.cmd" update
scripts\strata-setup.cmd
```
