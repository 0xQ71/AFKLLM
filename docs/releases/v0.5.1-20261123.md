# AFKLLM 0.5.1-20261123

Офлайн-перевод: рассуждения модели в DeepSeek Harness и `harness-watch` переводятся на русский прямо на ПК, без
Microsoft и без интернета. `/image` понимает русские промпты, а `/image-clean` чистит только текущий чат.

## Что нового

- **Офлайн-переводчик в `afk api`** (`POST /translate/translatetext`, протокол переводчика Edge):
  - модели OPUS-MT tc-big (Helsinki-NLP, CC-BY 4.0) в CTranslate2 int8, английский → русский и русский → английский;
  - работает на процессоре: 2 потока, низший приоритет, видеокарта не нужна, около 300 МБ ОЗУ;
  - код, пути, имена файлов и идентификаторы не переводятся;
  - запускается при первом запросе (около 1,3 с) и сам выключается через 15 минут простоя;
  - пока переводит, Flash-Next генерирует примерно на 12 % медленнее, в остальное время влияния нет;
  - тексты не пишутся на диск и в логи; переводы чата Harness хранит внутри этого чата.
- **DeepSeek Harness**: перевод рассуждений снова включён, но идёт через `afk api` (`bingEndpoint` в профиле);
  `harness-watch` использует тот же переводчик.
- **`/image` по-русски**: промпт переводится на английский локально (Qwen-Image лучше понимает английский), английский
  вариант показывается в ответе команды.
- **`/image-clean` по чатам**: у каждого чата своя папка картинок; команда удаляет картинки текущего чата, их копии
  ComfyUI и ярлыки «Недавние», не трогая другие чаты. `/image-clean all` чистит всё. Папка картинок исключена из
  поискового индекса Windows.
- **`scripts\mt-setup.cmd`**: окружение Python, загрузка и конвертация моделей (около 470 МБ в `C:\Models\mt`),
  самопроверка. `scripts\setup.cmd` запускает его сам.
- Правило агента для npm-пакетов: API брать из установленных `.d.ts`, без проб `node -e` и чтения исходников
  библиотеки; ошибки ловит сборка.

## Обновление

```powershell
git pull; npm install
scripts\mt-setup.cmd
powershell -ExecutionPolicy Bypass -File harness\install-profile.ps1
```

После этого перезапустите `afk api` и DeepSeek Harness (ярлыки «AFKLLM — выключить всё» и «AFKLLM — запустить»).
