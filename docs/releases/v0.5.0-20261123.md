# AFKLLM 0.5.0-20261123

Большая модель на обычном ПК: **Qwen3.8-Flash-Next** (MoE 125B, 6B активных) на движке
[Strata](https://github.com/Niko1221/Strata) с родным контекстом **256K** для ПК с 64 ГБ ОЗУ и 16 ГБ VRAM.
Подготовка ПК одной командой, хуки как в Claude Code для DeepSeek Harness, ярлыки на рабочем столе.

## Что нового

- **Профиль `flash`**: Qwen3.8-Flash-Next IQ3_XXS (99,4 % качества BF16), 55–85 t/s генерации и 750–1850 t/s
  чтения промпта (llama.cpp на тех же файлах: 18,5 и 300). Контекст 262 144 токена, KV int8 (3 ГБ на 256K),
  кэш разговора в ОЗУ: побочный запрос не выбивает основной диалог. Мышление xhigh до 32K токенов на шаг,
  сэмплинг из карточки модели. На 200K модель находит 3 из 3 спрятанных фактов.
- **Модель по железу**: `flash` на ПК с 64 ГБ ОЗУ и настроенной Strata, иначе `q38` (27B, 104K, 16 ГБ VRAM).
- **`scripts\setup.cmd`**: проверяет железо и советует модель, скачивает её с докачкой и проверкой SHA-256 (уже
  скачанные файлы только проверяет), ставит Strata и пресет, профиль DeepSeek Harness и ярлыки.
- **Ярлыки на рабочем столе**: «AFKLLM — запустить», «AFKLLM — остановить модель» (Harness остаётся),
  «AFKLLM — выключить всё».
- **Хуки для DeepSeek Harness** (`harness/dsh-hooks-afkllm`, команда `/hooks`):
  - защита: запрещены команды, ломающие ПК (удаление диска или профиля, форматирование, diskpart, перезагрузка,
    отключение Defender); перед `git push --force`, `reset --hard`, `clean -f`, `branch -D` и «скачать и выполнить»
    Harness спрашивает;
  - проверка синтаксиса после каждой правки: Python, JS, TypeScript (через `typescript` проекта), JSON,
    PowerShell, маркеры конфликта; ошибки сразу видит модель;
  - проверка перед концом хода: сломанный файл или упавший Stop-хук проекта (например, тесты) возвращает агента
    к работе, не больше 3 раз за ход;
  - уведомление Windows, когда ход шёл дольше минуты;
  - свои хуки в формате Claude Code: `~/.dsh/hooks.json` и `<проект>/.dsh/hooks.json` (файл проекта
    запускается только после `/hooks trust`, после любого изменения снова требует доверия).
- **Навыки агента** `security-review` (только доказанные уязвимости) и `test` (тесты, которые ловят настоящий баг,
  без ослабления проверок).
- **`scripts\afk-stop.cmd`**: остановить модель, прокси, ComfyUI и Harness и освободить VRAM одной кнопкой.
- Окно модели показывает работу Strata по-русски; Ctrl+C останавливает модель вместе с дочерними процессами.
- Правила агента: обе модели, обход ограничения песочницы Harness на временные папки Python 3.13.

## Быстрый старт

```powershell
git clone https://github.com/0xQ71/AFKLLM; cd AFKLLM; npm install
scripts\setup.cmd
```

## Файлы

| Файл | Что это |
|------|---------|
| `afk.exe` | CLI и бэкенд одним файлом, Node.js не нужен |
| `AFKLLM-0.5.0-20261123-x64-setup.exe` | Desktop-приложение |

Модели, Strata, llama.cpp (b12063) и ComfyUI ставятся отдельно: `scripts\setup.cmd` или README, «Рекомендуемая
модель» и «Установка».
