# AFKLLM 0.5.4-20261127

Чтение экрана: тест, контрольная или квест в игре — одна горячая клавиша, и модель присылает ответ в чат DeepSeek
Harness и уведомлением Windows. Уровни размышления low и medium теперь действительно быстрее.

## Что нового

- **Чтение экрана** (плагин Harness `harness/dsh-screen-afkllm`):
  - `Ctrl+Alt+S` в любом окне снимает это окно и отправляет в последний чат Harness с заданием «прочитай, реши,
    первой строкой — «Ответ: …»». Ответ приходит в чат, а строка «Ответ: …» — ещё и уведомлением Windows, так что из
    игры выходить не нужно.
  - `/screen [вопрос]` в Harness снимает окно, которое было перед ним; `/screen status` показывает состояние клавиши.
  - Скриншот решается на своём уровне размышлений, по умолчанию `low`; после ответа у чата остаётся его прежний
    уровень. `/screen effort low|medium|high|chat` меняет уровень (сохраняется), `/screen high [вопрос]` — разово.
  - Настройки в `cordis.patch.yml`, блок `screen-afkllm`: `hotkey`, `effort`, `notify`, `prompt`.
  - Игры в эксклюзивном полноэкранном режиме могут сниматься чёрными: включите оконный режим без рамки.
- **low / medium с ограничением размышления** (`flash`): прокси `afk api` добавляет `reasoning_budget_tokens` 2048
  для low и 4096 для medium, если запрос не задал свой. Сами уровни шаблона почти не меняли время, а хитрое задание
  могло думать минутами:

  | Скриншот | без лимита (low / medium / high) | low с лимитом |
  |---|---|---|
  | обычный вопрос теста | 5–13 с | 5–13 с |
  | квест с шифром Цезаря | 9–176 с, medium один раз ошибся | 13–18 с, 3 из 3 верно |
  | 6 страниц 1-го курса (матанализ, линейная алгебра, ДУ, информатика, английский, русский) | high 10–33 с | 5–18 с, всё верно |

  high не меняется: потолок 32K токенов, как раньше.
- `harness.cmd` пишет, что читает список моделей: первый запуск после перезагрузки молчал ~10–15 с.

## Обновление

```powershell
git pull; npm install
powershell -File harness\install-profile.ps1
```

`install-profile.ps1` подключает плагин; если профиль Harness правится вручную, добавьте блок `screen-afkllm` из
`harness\dsh-profile\cordis.patch.yml`. Затем перезапустите прокси и Harness (ярлыки «AFKLLM — выключить всё» и
«AFKLLM — запустить»).
