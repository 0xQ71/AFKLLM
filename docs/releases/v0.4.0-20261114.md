# AFKLLM 0.4.0-20261114

Новая линия AFKLLM: вместо IDE со своим агентным циклом появилось **headless-ядро агента** и три входа в него:
CLI `afk`, бэкенд `afk api` для внешних агентов (в первую очередь DeepSeek Harness) и Desktop-приложение на том же
ядре.

## Что внутри

- **CLI `afk`**: агент в терминале в духе Claude Code. Инструменты `Read` / `Write` / `Edit` / `Glob` / `Grep` /
  `Shell` / `TodoWrite` / `Task` / `Screenshot` / `GenerateImage`, режимы `default` / `acceptEdits` / `plan` /
  **AUTO MODE**, мышление всегда включено и передаётся между шагами, сжатие контекста на 80 %, сессии с
  продолжением (`afk -c`), картинки в промпте (`@файл`, Ctrl+V).
- **`afk api`**: OpenAI-совместимый `/v1` на 127.0.0.1:18300, MCP `/mcp` (`generate_image`, `screenshot`,
  `web_search`), `/search` (поиск без ключей), смена модели по полю `model`, `--lan` для других ПК.
- **`afk llama`**: модель в собственном окне с живым прогрессом на русском. Прокси можно перезапускать, модель и
  KV-кэш остаются.
- **Генерация изображений**: Qwen-Image 2.1 через ComfyUI, GPU-своп с сохранением KV-кэша LLM. Метаданные из PNG
  вырезаются.
- **DeepSeek Harness**: готовый профиль (`harness/dsh-profile`, ставится `harness/install-profile.ps1`), плагин
  поиска с карточкой источников, `/image` для приватной генерации без языковой модели, монитор сессии
  `scripts/harness-watch.mjs`, запуск всего одной командой `scripts\harness.cmd`.
- **Рекомендуемая модель**: Qwen3.8 27B (baa-ai RAM-13GB) со встроенным MTP и LM-головой Q5_K, 104K контекста на
  16 ГБ VRAM, ~40–70 t/s, зрение через проектор на CPU. Профили `q38` / `q38-128k` / `q38-160k`.
- **Бенчмарки** `scripts/stage0`: скорость, кэш, tool calls, заполнение контекста, needle, coder-eval, агентные
  задачи.

## Файлы

| Файл | Что это |
|------|---------|
| `afk.exe` | CLI и бэкенд одним файлом, Node.js не нужен |
| `AFKLLM-0.4.0-20261114-x64-setup.exe` | Desktop-приложение |

Модели, llama.cpp (b12063) и ComfyUI ставятся отдельно, см. README: «Рекомендуемая модель» и «Установка».

Установщики пока не подписаны: Windows может показать «Неизвестный издатель».
