# AFKLLM 0.2.0-20260811

Current **0.2** line (build 2026-08-11), compared to the first public **0.1.0** / **0.1.0-20260807**.

Semver everywhere: `0.2.0-20260811` (package, window title, Help → Version, status bar, installer filename).

This release folds **0.2.0-20260810** features plus reliability polish from **20260811**.

## What’s new since 0.1.0

### 🧭 First-run onboarding

- Full-screen welcome → choose **Coding agent** and/or **Image generation**
- Model step: chat GGUF, optional **Vision** (auto-suggested), image-gen stack when enabled
- **Continue later** without blocking on a chat model
- Tip to finish setup in Settings → Model / Store

### 👁 Vision & file attach

- Attach photos: VRAM cold-swap (unload chat → vision describe → restore chat)
- Vision GGUF + mmproj; autofill from Models (e.g. Qwen3-VL)
- Attach **any file** (drag/drop, paste, file button): PDF/DOCX text (+ scanned pages via vision), text inline, images with thumbs
- Click chat photos → in-app lightbox
- `@codebase` for full-repo search hints; open editors still feed the agent

### 🖼 Local image generation (FLUX / sd-cli)

- Settings → Agent master switch + composer **Image (Фото)** mode
- Agent tool `generate_image` via [stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp) (`sd-cli`)
- Multimodal paths: diffusion, VAE, CLIP-L, T5, optional LLM; Store picks + autofill
- **vram** mode: diffusion + **VAE on GPU**, T5/CLIP on CPU (faster decode)
- Prefer **non-scaled** T5 (`t5xxl_fp8_e4m3fn`) — `*_scaled` often yields blank white with FLUX
- Hires fix in one sd-cli job (~2× steps); blank detection; Settings negative prompt (text/glyph ban list)
- Favicon via `generate_image` blocked; agent falls back to CSS/placeholder on hard image failure

### 💬 Agent & chat (vs 0.1)

- Auto-title chats from the first prompt (sidebar + header)
- Small-file edits: prefer full `write_file overwrite`; fuzzy `apply_patch` / `apply_diff`
- Less premature context compaction (slim write history, higher threshold)
- Think-through: answers only inside `<think>` promoted to a visible reply
- Soft tool-loop / incomplete-write guards (carried from 0.1.0-20260807 + tightened)

### 🛠️ Editor & IDE (unchanged core from 0.1)

- Monaco FIM + Ctrl+K, multi-repo rail, Browser / Terminal, git sidebar
- Problems, TS/JS LSP helpers, themes, RU / EN UI

### ⚡ Models & runtime

- Hugging Face store (chat / vision / image-gen sidecars)
- Thin llama.cpp packs (CPU / CUDA / Vulkan)
- Slot orchestration: unload chat for vision / image gen, then restore
