# AFKLLM 0.2.0-20260811

Build (2026-08-11) on top of **0.2.0-20260810**.

Semver everywhere: `0.2.0-20260811` (package, window title, Help → Version, status bar, installer filename).

## 🖼 Image generation

- FLUX: keep VAE (+ TE) on CPU in `vram` weight mode to avoid blank white frames
- Base-first generation; fail fast on deterministic blank output (no useless second full pass)
- Prefer **non-scaled** T5 (`t5xxl_fp8_e4m3fn.safetensors`); `*_fp8_*_scaled` often yields blank white with sd-cli + FLUX
- Autofill / Store copy updated accordingly; Settings hint warns about scaled T5

## 💬 Agent & chat

- Auto-name chat from the first prompt and propagate title to the sidebar
- Small files: prefer `write_file overwrite`; fuzzy matching for `apply_patch` / `apply_diff`
- Less premature context compaction (slimmer write history, higher compact threshold)
