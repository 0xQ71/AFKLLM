# AFKLLM 0.3.0-20260825-alpha

**Pre-release (alpha).** Build date 2026-08-25. Not a stable production tag.

Semver everywhere: `0.3.0-20260825-alpha` (package.json, window title, Help → Version, status bar, NSIS `AFKLLM-0.3.0-20260825-alpha-x64-setup.exe`).

This is the first **0.3** line: the host — not the model — owns when a turn is done, whether files are complete, whether a CLI actually ran, and whether a preview is real. Compared with public **0.2.0-20260811**.

GitHub Release for this tag must be marked **pre-release**. In-app “check for updates” still ignores GitHub pre-releases, so **0.2 stable installs will not auto-jump to this alpha**. Install the alpha only if you want to test the new agent loop.

---

## Why 0.3 (one paragraph)

0.2 could chat, edit, preview, and generate images. 0.3 is about **not lying**: do not stop because a `.go` file exists; do not call a static `index.html` `npm run dev`; do not treat “I’ll fix the import next” as a closer; do not tick compile because the plan said compile; do not rewrite a landing into Python; do not hunt GitHub when the brief already has the facts. The agent executes leaked tool markup, keeps Think/stats, patches the stack that is on disk, and only pins a user-visible closer when evidence says the work happened.

## Agent loop (host)

### Execute, don’t narrate

- **Leaked tool XML runs.** If the model dumps `<tool_call>` / `write_file` / `run_shell` into prose instead of the API, the host parses and executes it. The turn does not die as “the model forgot tools.”
- **Think and stats stay.** Every `<think>` block and generation stats chip remains in the thread. The host does not strip reasoning to “save space” mid-turn.
- **No regex veto on README / second writes.** Fetching a README or writing a second file is not blocked by a brittle “one write only” pattern. Completeness is evidence, not a write counter.
- **Live Think.** Reasoning streams into the UI as it arrives. The reasoning token budget resets **per model call**, not once per chat.
- **Feed scroll.** The transcript no longer snap-backs to the top while tokens stream.

### Stack-agnostic work

- **Patch the stack that exists.** Python / Go / Node / C++ / Java / C# get surgical `apply_diff` + stack verify. The host must not pivot a backend bug into a new HTML landing.
- **Plan rows are not the truth.** A row that says “compile” ticks only on a real compiler (`cl`, `g++`, `go build`, `javac`, `csc`, …) with a real exit. Summarizing the plan in chat does not tick it.
- **Q&A / tool loops stop.** Repeated identical tools, empty Q&A ping-pong, and “continue with the next step” with no tool are cut. The host asks for a closer or an honest fail — not another identical shell.

### Apply on Chat (Ornith)

- **`apply_diff` and Ctrl+K use the Chat GGUF.** There is no second “Apply” model in VRAM. Settings copy says so. Landing and surgical edits share one loaded chat model (Ornith in the live campaign).

### Vision

- **Keep vision coresident or reuse chat VL.** If the chat GGUF is already vision-capable, do not cold-swap to a second VL just to describe an attach. If a VL slot is already loaded, reuse it. Landings still have to write files after an image turn.
- **8k cap on agent completions** so a VL describe cannot eat the whole ctx and skip `write_file`.

### History compact

- **Compact only at 99% of real context**, not at a fake 8k ceiling inside a 131k window. Successful preview turns pin a **visible closer before stop**, so compact cannot eat the last user-facing sentence.

## From-scratch tracks (evidence gates)

These are host rules. They apply to any language the brief names — not a list of recipes.

### HTML / CSS landing

- **Missing or stub CSS/HTML is not a finished file.** Empty `styles.css`, leaked tool markup inside HTML, or a 200-byte “TODO stylesheet” cannot FILE_COMPLETE the path. The agent must write the real file.
- **i18n is not a rewrite.** EN/RU (or extra locales) in the brief means strings / `data-i18n`, not a second copy of the site. Whole-file rewrite of a complete landing is blocked.
- **Sanity on switcher / nav / theme.** If the brief asked for a language switcher, nav, or theme toggle, the host fails the turn when those still don’t match after “done.”
- **No GitHub scavenger hunt** when the brief already has brand, sections, and colors. Do not clone a random repo to “get inspiration.”

### Python

- **stdin is not a CLI.** A program that only reads stdin is not “ran the CLI.” The host wants argv or a real invocation with stdout.
- **Keep shell stdout** in the chip. Do not close on a silent `exit 0`.
- **Drop PLAN_ONLY echo** and unsolicited landing titles when the user asked for a script.

### Vite + React

- **Do not hang or stop mid-scaffold.** `package.json`, `vite.config.*`, `index.html`, `src/main.*`, `src/App.*` must exist before the plan can say done.
- **End after a real preview** (`localhost` / Browser tab) **plus one closer outside `<think>`**.
- **That closer is plain prose** immediately before `files_changed` — not a JSON blob, not an English chain-of-thought.
- **EDIT_SANITY** does not fire on PascalCase components (`FishingGame`) or on `package.json` `"build"` script wording. Those are not “unbound click handlers” or “wrong stack.”
- Interactive `npm create vite` is rewritten to **current directory, `--no-interactive`**. A nested `fishing-game/` folder is wrong when the user said this folder.
- Host rewrites `npm run dev` onto a **safe port** and treats labeled Vite `Local:` as preview evidence.

### Go

- **Hide `afk-run-*.ps1` chrome** from the terminal chip (wrapper path, `SilentlyContinue`, leftover `ntinue`).
- **Refuse brace-breaking patches.** A diff that splits `func (` across a broken brace is rejected; the file stays compilable.
- **Vacuous stdout is not done.** `exit 0` + “no words” / empty tokenizer is `CLI_EMPTY` / `GO_SPLIT` — fix and re-run, do not closer.

### Windows C++ (and the same idea for any native toolchain)

- **Rewrite `where` / `nul` / bare `.exe`** into PowerShell that actually runs (`where.exe`, `>$null`, `.\app.exe`).
- **Refuse compiler installs** (`winget`/`choco` MinGW, random GCC tarballs). Use `cl` or `g++` already on the machine. The host does not stall the turn on “please install Visual Studio.”
- **Tick compile only on real `cl` / `g++`** output, not on a plan sentence.

### Java / C# / CLI closers

- **A path on disk is not a successful run.** `WordFreq.java` existing ≠ `java WordFreq` with stdout.
- **Leftover narration is not a closer.** “I forgot the import, I’ll fix it,” “now I need to run javac,” “Need to continue with main” are next-action, not Help → done.
- **Host closer for CLI** only when `cliVerified`: program written **and** run, stdout in the terminal chip. If compile failed, the closer must **not** claim success.
- **FILE_COMPLETE vs failed compile.** A failed `javac` / `csc` / `cl` / `go build` unlocks a full rewrite of that source. A complete file that never failed compile still requires `apply_diff`.

## Shell / PowerShell (Windows host)

- **`&&` / `||`** outside quotes → `if ($?)` / `if (-not $?)`. Short-circuit semantics stay.
- **`which`** → `where.exe`. **`cl /?` / `csc /?`** (often piped to `Select-Object -First`) → `where.exe cl` so the PTY does not hang on help.
- **Bash heredoc / here-string** (`cat > file <<EOF`, `<<<`) → PowerShell here-string / `Set-Content`.
- **`2>/dev/null` / `>nul`** → `$null`.
- **PTY chrome stripped:** `SilentlyContinue`, wrapper `& '...\afk-run-….ps1'`, `__AFK_EXIT_*`.
- **Identical shell fingerprint** is reset after a successful write/apply so `TOOL_LOOP` does not fire on the first real `go run` after an edit.
- **`cmd &` chaining** (single ampersand) is still a known hole in this alpha if the model emits `where a & where b` without `&&`; the model can recover with `;`. Tracked as follow-up, not a 0.3 blocker.

## Closers & completeness (product rules)

- **User-facing closer** is Russian when the UI is Russian. Chain-of-thought “I should write a summary in Russian” is stripped.
- **Preview closer** must mention the in-app Browser when a preview actually opened. Static HTML must **not** say `npm run dev`. Vite/React may mention it.
- **False success prose** (“files created”, “done”) is noise unless it is a host closer (`Preview is open in the app` / `see the terminal chip`).
- **Honest fail** when the last compile/run failed: do not report the task as done.
- **Acceptance / plan:** CLI-verify steps (“run it”, “show stdout”) close only on `cliVerified`, not on `edited`. A “short summary” row is meta, not leftover file work.

## What we explicitly did **not** ship as “fixed” in this alpha

- **C++ `cl` still failing** on a bad `wordfreq.cpp` is a **model** quality miss. The host correctly refuses to closer. Do not “fix” that with a fake success.
- **Java ranking `1, 3, 5…`** is model code, not a host bug.
- **Go stdin path** unused when the model only passed a file argument — model.
- **Auto-update 0.2 → 0.3-alpha** is disabled on purpose (pre-release).
