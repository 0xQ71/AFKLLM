# AFKLLM 0.1.0-20260807

Build on top of the first public **0.1.0** release (2026-08-07).

Semver everywhere: `0.1.0-20260807` (package, window title, Help → Version, status bar, installer filename).

## 🔧 Agent reliability

- Settings opens as an **overlay** — chat stays mounted; Settings / Unload blocked while generating
- Successful `write_file` chunks persist to disk (no more false **Edited · failed**)
- Truncated streams continue with append; no mid-stream abort when `relative_path` arrives after `content`
- Clearer edit activity (partial vs failed) and soft tool-loop / markup-leak guards

- README EN / RU with product screenshots
- GitHub issue/PR templates, CI + Windows release workflow
- Removed unused bench / e2e scaffolding

- Local installer verify script; public Authenticode via SignPath Foundation (OSS) planned — see `docs/guides/code-signing.md`
