# AFKLLM 0.2.0-20260810

Minor release (2026-08-10) on top of **0.1.0-20260807**.

Semver everywhere: `0.2.0-20260810` (package, window title, Help → Version, status bar, installer filename).

## 🧭 First-run onboarding

- Full-screen welcome → choose **Coding agent** and/or **Image generation (experimental)**
- Model step: pick/download chat GGUF, optional **Vision** (auto-suggested from Models dir), image-gen stack when enabled
- **Continue later** with a short tip to Settings → Model / Store
- Chat model is no longer required to finish setup

## 👁 Vision attach

- Attach photos in chat: exclusive VRAM cold-swap (unload chat → vision → describe → reload chat)
- Optional vision GGUF + mmproj; autofill from Models when empty (e.g. Qwen3-VL)
- Vision result injected as text for the coding agent
- Clicking a sent photo opens the in-app lightbox (same as tree PNGs)
- Attach **any file** via drag/drop, Ctrl+V, or the file button — Cursor-style badge + blue name in the chat bubble. PDF/DOCX extract text (scanned PDFs → vision pages); text files inline; images keep thumbs + vision. Legacy `.doc` → save as DOCX
- Composer **+** context shortcut removed — type `@codebase` when you need a full-repo search hint; open files still feed the agent automatically

## 🖼 Image generation

- Composer **Image** mode gated by Settings → Agent → Image generation (master switch)
- `generate_image` via stable-diffusion.cpp / sd-cli (FLUX stack, autofill paths, hires/VAE hardening)
- When Image mode is off, the tool is hidden from the agent and rejected in main

## 💬 Agent & UI polish

- Think-through: answers that landed only inside `<think>` are promoted to a visible reply
- Context usage semicircle gauge fill fixed (no more crooked arc)
- Welcome copy reminds users to pick models in Settings
