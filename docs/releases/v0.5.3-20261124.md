# AFKLLM 0.5.3-20261124

Зрение модели `flash` переехало на видеокарту: картинки читаются в 7–8 раз быстрее и с мелкими надписями, а когда
картинок нет, это ничего не стоит.

## Что нового

- **Эластичное зрение на GPU** (Strata 0.2.20): энкодер картинок запускается с первой картинкой, на время работы
  берёт у кэша экспертов ~0,8 ГБ видеопамяти и возвращает их через 60 с после последней картинки. Картинка — до
  4096 токенов.

  Контактный лист из 36 кадров (1800×2665), время до первого токена и точность (18 слов титров + мелкая плашка):

  | Токенов | CPU (было) | GPU | Титры | Мелкая плашка |
  |---|---|---|---|---|
  | 1K | 11 с | 2,8 с | 16–17 из 18 | нет |
  | 2K | 31–34 с | 4,8 с | 17–18 из 18 | почти |
  | 4K | 77 с | 10 с | 17–18 из 18 | да |

  Первая картинка после простоя дольше на 3–16 с (запуск энкодера). Пока энкодер работает, чтение больших новых
  кусков промпта на ~33 % медленнее, генерация не меняется; после остановки энкодера всё возвращается полностью.
- **Видеопамять взаймы без выгрузки модели**: `POST http://127.0.0.1:18301/v1/vram {"reserve_mib": N}` освобождает
  5,6–8,2 ГБ за доли секунды (например, под рендер), `{"reserve_mib": 0}` возвращает всё за ~1 с; модель всё это
  время отвечает, медленнее.
- Документация: замеры и устройство в `docs/cli.md`, README.

## Обновление

```powershell
git pull; npm install
```

Перезапустите модель (ярлыки «AFKLLM — выключить всё» и «AFKLLM — запустить»). Нужна Strata 0.2.20 (см. 0.5.2).

## Файлы

| Файл | Что это |
|------|---------|
| `afk.exe` | CLI и бэкенд одним файлом, Node.js не нужен |
| `AFKLLM-0.5.3-20261124-x64-setup.exe` | Desktop-приложение |

Модели, Strata, llama.cpp (b12063), ComfyUI и переводчик ставятся отдельно: `scripts\setup.cmd` или README.

Установщики пока не подписаны: Windows может показать «Неизвестный издатель».
