# Changelog

Заметки к каждому релизу публикуются в описании [GitHub Release](https://github.com/0xQ71/AFKLLM/releases),
полный текст лежит в [`docs/releases/`](docs/releases/).

## 0.5.4-20261127

Чтение экрана для тестов и квестов (`Ctrl+Alt+S` / `/screen` в Harness), быстрые low и medium.

Подробно: [`docs/releases/v0.5.4-20261127.md`](docs/releases/v0.5.4-20261127.md).

- Плагин `dsh-screen-afkllm`: скриншот окна уходит в чат, модель решает и отвечает в чате и уведомлением Windows;
  свой уровень размышлений для скриншотов (по умолчанию low), `/screen effort`, `/screen high [вопрос]`.
- `flash`: low / medium ограничивают размышление 2048 / 4096 токенами — квест с шифром 13–18 с вместо 9–176 с,
  страницы 1-го курса 5–18 с, всё верно.
- `harness.cmd` сообщает о чтении списка моделей после перезагрузки.

## 0.5.3-20261124

Зрение `flash` на видеокарте: в 7–8 раз быстрее и с мелкими надписями, видеопамять взаймы без выгрузки модели.

Подробно: [`docs/releases/v0.5.3-20261124.md`](docs/releases/v0.5.3-20261124.md).

- Эластичный энкодер картинок Strata на GPU, до 4096 токенов на картинку, память возвращается экспертам через 60 с
  после последней картинки: контактный лист 10 с вместо 77 (CPU), мелкие надписи читаются.
- `vram_elastic`: `POST :18301/v1/vram` одалживает 5,6–8,2 ГБ видеопамяти другой программе и возвращает её за ~1 с.

## 0.5.2-20261124

Strata 0.2.20 и DeepSeek Harness 0.2.3: запуск активной версии Strata и настройки, которые возвращают скорость нового движка на 16 ГБ.

Подробно: [`docs/releases/v0.5.2-20261124.md`](docs/releases/v0.5.2-20261124.md).

- `afk api` запускает сервер из активной версии Strata (после `strata update` она в `components\control\<версия>`).
- Настройки движка профиля идут в `user_args`, их сервер Strata не пересобирает.
- Профиль `flash` на Strata 0.2.20: `STRATA_NV_CHUNK=16` и `--vram-reserve-mib 350` — чтение промпта 1658 / 1984 т/с на 30K / 125K
  (без них 1020 / 1043, на 0.2.18 — 1591 / 1939), генерация как раньше.
- `scripts\strata-setup.cmd`: 256K и полный подбор настроек (`--tune thorough --retune`).
- Проверено с DeepSeek Harness 0.2.3-alpha.2.

## 0.5.1-20261123

Офлайн-перевод рассуждений и промптов `/image` на этом ПК, `/image-clean` по чатам.

Подробно: [`docs/releases/v0.5.1-20261123.md`](docs/releases/v0.5.1-20261123.md).

- Офлайн-переводчик в `afk api` (`/translate/translatetext`, протокол переводчика Edge): рассуждения в DeepSeek Harness
  и `harness-watch` переводятся на русский на этом ПК, а не через Microsoft. OPUS-MT tc-big в CTranslate2 int8 на
  процессоре (2 потока, низший приоритет, без видеокарты; код, пути и имена не переводятся), запускается при первом
  запросе и сам выключается через 15 минут простоя. Установка один раз: `scripts\mt-setup.cmd`.
- `/image`: русский промпт переводится на английский локально перед генерацией, английский вариант показывается в
  ответе команды (остаётся в чате до его удаления). Переводчик промпты не хранит.
- `/image-clean` удаляет только картинки текущего чата (у каждого чата своя папка `chat-<id>`) вместе с их копиями
  ComfyUI и ярлыками «Недавние»; `/image-clean all` чистит все чаты. Папка картинок исключена из индекса поиска Windows.
- Правило агента для npm-пакетов: API смотреть по установленным `.d.ts`, без проб `node -e` и чтения исходников
  библиотеки; ошибки ловит сборка.

## 0.5.0-20261123

Qwen3.8-Flash-Next на Strata (256K, по умолчанию на ПК с 64 ГБ), подготовка ПК одной командой, хуки как в
Claude Code для DeepSeek Harness, ярлыки на рабочем столе.

Подробно: [`docs/releases/v0.5.0-20261123.md`](docs/releases/v0.5.0-20261123.md).

- Хуки для DeepSeek Harness (плагин `harness/dsh-hooks-afkllm`, `/hooks`): защита от разрушительных команд,
  проверка синтаксиса после каждой правки, проверка перед концом хода с возвратом агента к сломанным файлам или
  упавшим тестам, уведомление Windows после долгого хода, свои `PreToolUse` / `PostToolUse` / `Stop` в формате
  Claude Code (`~/.dsh/hooks.json`, `<проект>/.dsh/hooks.json` после `/hooks trust`).
- Навыки агента `security-review` и `test`.
- Профиль `flash`: Qwen3.8-Flash-Next IQ3_XXS (MoE, 47 ГБ весов) на движке [Strata](https://github.com/Niko1221/Strata)
  для ПК с 64 ГБ ОЗУ: родной контекст 256K, 55–85 t/s и 750–1850 t/s чтения промпта против 18,5 и 300 у llama.cpp
  на тех же файлах, мышление xhigh до 32K на шаг с сэмплингом из карточки модели.
  Работает через тот же `afk api` (прокси, смена модели, GPU-своп для картинок), есть в профиле DeepSeek Harness.
  Разовая настройка: `scripts\strata-setup.cmd`.
- Модель по умолчанию выбирается по железу: `flash` на ПК с 64 ГБ ОЗУ и настроенной Strata, иначе `q38`
  (`defaultProfile` в `~/.afkllm/cli.json` закрепляет выбор).
- `scripts\setup.cmd`: подготовка ПК одной командой — проверка железа и рекомендация модели, загрузка с докачкой и
  проверкой SHA-256 (`download-models.py --flash`), установка Strata и пресета, профиль DeepSeek Harness, ярлыки.
- Ярлыки на рабочем столе: «AFKLLM — запустить», «AFKLLM — остановить модель», «AFKLLM — выключить всё».
- `scripts\afk-stop.cmd`: одной кнопкой остановить модель, прокси, ComfyUI и DeepSeek Harness и освободить VRAM.
- Правила агента: обе модели, и обход ограничения песочницы Harness на временные папки Python 3.13.
- Окно модели (`afk-llama.ps1`) показывает работу Strata по-русски; Ctrl+C останавливает модель вместе с дочерними
  процессами.

## 0.4.0-20261114

Headless-ядро агента и три входа в него: CLI `afk`, бэкенд `afk api` (OpenAI `/v1` + MCP + поиск) для DeepSeek
Harness и других клиентов, Desktop-приложение на том же ядре. Генерация изображений Qwen-Image 2.1 с GPU-свопом,
профиль Qwen3.8 27B + MTP на 104K для 16 ГБ, готовый профиль DeepSeek Harness, бенчмарки моделей.

Подробно: [`docs/releases/v0.4.0-20261114.md`](docs/releases/v0.4.0-20261114.md).
