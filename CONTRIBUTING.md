# Contributing

Thanks for contributing to AFKLLM.

## Development

1. Fork and clone the repository.
2. `npm install`
3. `npm run dev`

See [docs/guides/development.md](docs/guides/development.md) for stack details, packaging, and release notes.

## Before opening a PR

- Run `npm run typecheck`
- Keep PRs focused; describe what / why / how you tested

## Issues

- Bugs: use the **Bug report** template
- Ideas: use the **Feature request** template
