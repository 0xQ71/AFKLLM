Features

🤖

Agent-first IDE

Chat and tools on the left, editor / browser / terminal on the right — agent-driven workflow.

🧠

Local Models

Read, write, patch GGUF models. Terminal, search, git, web search — all on-device.

💻

Monaco Editor

FIM ghost text, Ctrl+K inline edit — the same editor you know and love.

👁️

Vision & Images

Attach vision images, generate images locally with FLUX / sd-cli.

🔒

Privacy First

Core loop runs on-device. MIT license. Windows x64 installer from Releases.

📦

HF Store

Browse and manage models from Hugging Face store directly in the IDE.

How It Works

1

Install AFKLLM

Download the Windows x64 installer from GitHub Releases and install.

2

Add Models

Browse Hugging Face store or add local GGUF files. Read, write, patch models on-device.

3

Start Coding

Chat with your local model, use tools, edit in Monaco — all locally, no cloud.

Why Local?

Privacy

Your code, your models, your data — never sent to a cloud server.

Offline

Works without internet. No API keys, no subscriptions, no dependencies.

Control

Choose your model, tune parameters, patch weights — full control over your stack.
